# Credit Scoring Model using Machine Learning

## Objective
To predict whether an individual is creditworthy or risky based on financial and personal data.

## Dataset
German Credit Dataset

## Features Used
- Age
- Job
- Housing
- Saving accounts
- Checking account
- Credit amount
- Duration
- Purpose

## Approach
- Data preprocessing and handling missing values
- Encoding categorical variables using Label Encoding
- Splitting data into training and testing sets
- Training a Random Forest Classifier

## Model Used
Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Results
The model achieved approximately 82 percent accuracy.
It performed well in identifying creditworthy individuals but showed moderate performance in detecting risky applicants.

## Conclusion
The model can be used to assist financial institutions in evaluating loan applicants and reducing risk.
